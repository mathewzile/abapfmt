# abapfmt for VS Code

Formats ABAP and CDS (DDL/DCL) code with the abapfmt language server: Format Document, Format Selection and format on save.

Set `"editor.defaultFormatter": "abapfmt.abapfmt"` for the `abap` and `abap-cds` languages. Rules are configured in an `abapfmt.json` next to your code (or in a parent folder).
